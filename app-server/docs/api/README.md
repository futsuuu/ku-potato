# KU-POTATO HTTP API

- **OpenAPI Version:** `3.2.0`
- **API Version:** `0.1.0`
- **License:** 

Single-account loopback API. Feature endpoints stream typed results, operation status, and progress using SSE. Replay the feature request to retry.
