## 仕様

### URL毎の状態共有

KU-LMSでは、URL毎に状態が共有される。

教材一覧が表示されている `/lms/homeHoml/doLinkKougi` を例に挙げる。
二つのタブでKU-LMSのホーム画面を開いてから異なる講義を開くと、同じURLで表示される。
そして、先に開いたタブをリロードすると後に開いた講義に切り替わってしまう。

ただし、教材一覧を表示するページにはURLが二種類ある。
講義一覧から遷移すると上記のURLだが、教材を開いてからパンくずリスト経由で教材一覧に戻ると `/lms/corsColl/doIndex` となる。
`/lms/homeHoml/doLinkKougi` と `/lms/corsColl/doIndex` におそらく違いはない。
そして、この二つのタブでこれらのURLを開いた場合は状態が共有されない。

### 教材IDの一意性

 二つのタブで異なる講義を同時に開いていてURLも同じという状況で、先に開いたタブで教材をクリックすると正しく遷移する。
 そのため、教材IDは講義に関わらず一意だと思われる。
