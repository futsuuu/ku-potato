# FileDownload

**Type:** `object`, no additional properties

- **`downloadUrl` (required)**: `string`, pattern: `^/materials/[A-Z]+[0-9]+/resources/SRS[0-9]+/file$`
- **`file` (required)**: [SavedFile](SavedFile.md)
- **`type` (required)**: `string`, possible values: `"file"`

**Example:**

```json
{
  "downloadUrl": "",
  "file": {},
  "type": "file"
}
```
