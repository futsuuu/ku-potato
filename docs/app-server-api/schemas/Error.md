# Error

**Type:** `object`, no additional properties

- **`message` (required)**: `string`
- **`reason` (required)**: `string`, possible values: `"invalid-input", "conflict", "authentication-required", "archive-data-missing", "material-not-found", "resource-not-found", "course-not-found", "unsupported-resource", "source", "timeout", "internal", "archive", "authentication-storage", "resource-storage", "not-found", "forbidden", "browser-start"`

**Example:**

```json
{
  "message": "",
  "reason": "invalid-input"
}
```
