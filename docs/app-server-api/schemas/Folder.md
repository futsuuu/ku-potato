# Folder

**Type:** `object`, no additional properties

- **`materials` (required)**: array of [Material](Material.md) | `null`
- **`name` (required)**: `string`
- **`classDate`**: `string`, format: `date`
- **`descriptionHtml`**: `string`

**Example:**

```json
{
  "classDate": "",
  "descriptionHtml": "",
  "materials": [
    {}
  ],
  "name": ""
}
```
