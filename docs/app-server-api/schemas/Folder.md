# Folder

**Type:** `object`

- **`materials` (required)**: array of [Material](Material.md)
- **`name` (required)**: `string`
- **`classDate`**: `string | null`, format: `date`
- **`descriptionHtml`**: `string | null`

**Example:**

```json
{
  "classDate": null,
  "descriptionHtml": null,
  "materials": [
    {}
  ],
  "name": ""
}
```
