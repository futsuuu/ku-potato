# ErrorDetail

**Type:** `object`, no additional properties

- **`location`**: `string`

  Where the error occurred, e.g. 'body.items\[3].tags' or 'path.thing-id'
- **`message`**: `string`

  Error message text
- **`value`**: `any`

  The value at the given location

**Example:**

```json
{
  "location": "",
  "message": "",
  "value": null
}
```
