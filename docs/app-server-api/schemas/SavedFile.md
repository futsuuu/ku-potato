# SavedFile

**Type:** `object`, no additional properties

- **`contentHash` (required)**: `string`
- **`originalFilename` (required)**: `string`
- **`originalSize` (required)**: `integer`, format: `int64`, minimum: `0`

**Example:**

```json
{
  "contentHash": "",
  "originalFilename": "",
  "originalSize": 0
}
```
