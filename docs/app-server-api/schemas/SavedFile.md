# SavedFile

**Type:** `object`

- **`contentHash` (required)**: `string`, minLength: `64`, maxLength: `64`, pattern: `^[0-9a-f]{64}$`
- **`originalFilename` (required)**: `string`
- **`originalSize` (required)**: `integer`, format: `int64`, minimum: `0`

**Example:**

```json
{
  "contentHash": "",
  "originalFilename": "",
  "originalSize": 0
}
```
